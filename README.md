# Thuthuzela Aid Community Centre Website

## Part 2 – Website Development

### Project Overview

The Thuthuzela Aid Community Centre website is a community-focused website designed to provide information about the organisation, its services, and ways that community members can get involved.

The website contains the following main pages:

- Home
- About Us
- Our Services
- Get Involved
- Contact Us

The website was developed using HTML5 and CSS3 in Visual Studio Code.
